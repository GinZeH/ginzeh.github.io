Firefly（流萤）博客主题文档
项目概述
项目名称：Firefly（流萤）- 一款清新美观的 Astro 静态博客主题模板
官方文档站：https://docs-firefly.cuteleaf.cn/zh/
GitHub 仓库：https://github.com/CuteLeaf/Firefly
作者：CuteLeaf（夏叶）
技术栈：Astro 框架，基于 Fuwari 模板二次开发
一、核心特性
高度可定制
20+ 个配置文件，灵活调整站点外观和功能
支持多种主题色，用户可自由切换
多种布局模式可选
现代技术栈
基于 Astro 框架，性能优异
支持 Tailwind CSS
响应式设计，适配各种设备
Markdown & MDX 支持
完整的 Markdown 语法支持
MDX 增强，可在文档中嵌入组件
代码高亮、数学公式、图表等丰富功能
双侧边栏布局
左右侧边栏可独立配置
多种小组件可选：个人资料、公告、音乐、分类、标签等
移动端自适应底部组件
多评论系统支持
Twikoo、Waline、Giscus、Disqus、Artalk
多语言支持
中文（简体 / 繁体）、英文、日文、俄文
丰富功能
音乐播放器（支持 Meting API 和本地音乐）
Live2D/Spine 看板娘
樱花特效等动画效果
相册功能（瀑布流布局）
番组计划 / 追番页面
友链、打赏、留言板等页面
二、快速开始
环境要求
Node.js 22.0 或更高版本
pnpm 包管理器（推荐）
Git
安装步骤
克隆仓库：git clone https://github.com/CuteLeaf/Firefly.git
安装依赖：pnpm install
启动开发服务器：pnpm dev
构建生产版本：pnpm build

三、基础配置
3.1 站点配置（siteConfig.ts）
基础信息
title：站点标题，默认 "Firefly"
subtitle：站点副标题，默认 "Demo site"
site_url：站点 URL
description：站点描述
keywords：站点关键词
lang：站点语言，支持 zh_CN、zh_TW、en、ja、ru
主题色
themeColor.hue：主题色色相（0-360），默认 165
themeColor.fixed：是否隐藏主题色选择器
themeColor.defaultMode：默认模式（light/dark/system）
页面宽度
pageWidth：页面最大宽度（rem），默认 100
卡片样式
card.border：是否开启卡片边框和阴影，默认 true
card.followTheme：卡片背景是否跟随主题色相，默认 false
导航栏
navbar.logo：导航栏 Logo，支持四种类型
Astro 图标库：{type: "icon", value: "..."}
public 目录图片：{type: "image", value: "/..."}
src 目录图片（推荐，自动优化）：{type: "image", value: "..."}
网络图片：{type: "url", value: "https://..."}
navbar.title：导航栏标题，默认 "Firefly"
navbar.widthFull：是否占满屏幕宽度，默认 false
navbar.menuAlign：菜单对齐（left/center），默认 "center"
navbar.followTheme：是否跟随主题色，默认 false
navbar.stickyNavbar：是否固定在顶部，默认 true
日期与时区
siteStartDate：站点开始日期（YYYY-MM-DD）
timezone：IANA 时区字符串，默认 "Asia/Shanghai"
提醒框（Admonitions）
rehypeCallouts.theme：主题（github/obsidian/vitepress/docusaurus），默认 "github"
文章配置
post.showLastModified：是否显示上次编辑时间，默认 true
post.outdatedThreshold：文章过期阈值（天），默认 30
post.sharePoster：是否开启分享海报，默认 true
post.generateOgImages：是否生成 OpenGraph 图片，默认 false
文章列表布局
postListLayout.defaultMode：默认布局（list/grid），默认 "list"
postListLayout.mobileDefaultMode：移动端默认布局
postListLayout.showTags：是否显示标签，默认 true
postListLayout.descriptionLines：简介显示行数，默认 2
postListLayout.allowSwitch：是否允许切换布局，默认 true
postListLayout.grid.masonry：是否开启瀑布流，默认 false
postListLayout.grid.columnWidth：网格卡片最小宽度（px），默认 320
分页配置
pagination.postsPerPage：每页文章数量，默认 10
页面开关
pages.friends：友链页面，默认 true
pages.sponsor：打赏页面，默认 true
pages.guestbook：留言板页面，默认 true
pages.bangumi：番组计划页面，默认 true
pages.gallery：相册页面，默认 true
categoryBar：分类导航栏，默认 true
Bangumi 配置
bangumi.userId：Bangumi 用户 ID
bangumi.mode：数据模式（static/dynamic），默认 "dynamic"
bangumi.apiUrl：Bangumi API 地址，默认 "https://api.bangumi.one"
bangumi.subjectBaseUrl：详情页地址前缀
bangumi.categoryOrder：类型排序，默认 ["anime", "book", "music", "game"]
统计分析
Google Analytics：analytics.googleAnalyticsId
Microsoft Clarity：analytics.microsoftClarityId
Umami：analytics.umamiAnalytics.websiteId 等
51la 统计：analytics.la51Analytics.Id 等
图像优化
imageOptimization.formats：输出格式（avif/webp/both），默认 "webp"
imageOptimization.quality：压缩质量（1-100），默认 85
imageOptimization.noReferrerDomains：防盗链处理域名列表
3.2 个人资料（profileConfig.ts）
avatar：头像路径
name：名称
bio：个人简介
links：社交链接列表
头像路径支持三种格式：
public 目录（以 / 开头）：不优化
src 目录（不以 / 开头）：自动优化（推荐）
远程 URL：不优化
社交链接属性：name、icon、url、showName
3.3 背景壁纸（backgroundWallpaper.ts）
壁纸模式
mode：壁纸模式（banner/fullscreen/overlay/none），默认 "banner"
switchable：是否允许用户切换壁纸模式，默认 true
图片配置
支持分别设置桌面端和移动端、多张图片随机显示、使用随机图 API
背景视频播放器
playerEnable：是否启用背景视频播放，默认 false
src.playerUrl：视频地址，支持单个或数组
common.playerMode：多视频模式（order/random），默认 "order"
通用配置（Banner 和 Fullscreen 共享）
文字遮罩暗度：common.dimOpacity，默认 0.2
首页横幅文字：common.homeText.title、subtitle 等
打字机效果：common.homeText.typewriter.enable、speed、deleteSpeed、pauseTime
导航栏透明模式：common.navbar.transparentMode（semi/full/semifull）
水波纹动画：common.waves.enable（会影响性能）
渐变过渡：common.gradient.enable（与水波纹互斥）
壁纸轮播：common.carousel.enable、interval、transitionEffect（fade/zoom/slide/kenburns）
Banner 模式配置
banner.position：CSS object-position 值，默认 "0% 20%"
Fullscreen 模式配置
fullscreen.position：CSS object-position 值，默认 "center"
Overlay 模式配置
overlay.switchable：是否允许调整透明模式参数
overlay.opacity：壁纸透明度（0-1），默认 0.8
overlay.blur：背景模糊度（px），默认 10
overlay.cardOpacity：卡片背景透明度（0-1），默认 0.5
3.4 导航栏（navBarConfig.ts）
预设链接：Home, Archive, Categories, Tags, Friends, Sponsor, Guestbook, About, Bangumi, Gallery
自定义链接属性：name、url、icon、external、children、pageKey
搜索配置：navBarSearchConfig.method（PageFind）
动态导航栏：根据 siteConfig.pages 自动调整显示
预装图标集：fa7-brands、fa7-regular、fa7-solid、material-symbols、simple-icons
3.5 侧边栏（sidebarConfig.ts）
布局配置
enable：是否启用侧边栏，默认 true
position：位置（left/right/both），默认 "left"
tabletSidebar：平板端是否显示，默认 true
showBothSidebarsOnPostPage：文章页是否显示双侧边栏，默认 false
可用组件类型
profile - 用户资料卡片
announcement - 公告栏
music - 音乐播放器
categories - 文章分类列表
tags - 标签云
stats - 站点统计
siteInfo - 站点信息
calendar - 文章日历
sidebarToc - 文章目录（仅文章页可用）
advertisement - 广告栏
3.6 侧边栏小组件
组件专属配置
分类 / 标签组件：collapseThreshold 折叠阈值
日历组件：calendar.showHeatmap 热力图
站点信息：siteInfo.unknownBuildPlatform 回退文本
广告组件：支持多个实例，每个实例独立配置和显示计数
四、功能配置
4.1 字体（fontConfig.ts）
enable：是否启用自定义字体
selected：选中的字体名称
bannerTitleFont、bannerSubtitleFont、navbarTitleFont、codeFont：各区域独立字体
内置字体
--font-zen-maru-gothic（日文圆体）
--font-inter（英文无衬线）
--font-jetbrains-mono（等宽字体）
--font-greatvibes（装饰性字体）
字体提供商：google、fontsource、local、bunny、fontshare、npm
4.2 代码块（expressiveCodeConfig.ts）
基于 Expressive Code。
darkTheme：暗色模式代码主题，默认 "one-dark-pro"
lightTheme：亮色模式代码主题，默认 "one-light"
代码折叠
pluginCollapsible.enable：是否启用折叠功能，默认 true
pluginCollapsible.lineThreshold：超过此行数显示折叠按钮，默认 15
pluginCollapsible.previewLines：折叠时显示的预览行数，默认 8
pluginCollapsible.defaultCollapsed：默认是否折叠长代码块，默认 true
语言徽章
pluginLanguageBadge.enable：是否启用语言徽章，默认 false
4.3 Mermaid 图表
内置能力，无需额外配置。在文章中使用 mermaid 代码块即可渲染。
支持：流程图、时序图、状态图等
4.4 PlantUML 图表（plantumlConfig.ts）
enable：是否启用 PlantUML 渲染，默认 true
server：PlantUML 服务地址，默认官方服务
lightTheme：亮色模式注入主题名
darkTheme：暗色模式注入主题名，默认 "cyborg"
4.5 评论系统（commentConfig.ts）
支持类型：none、twikoo、waline、giscus、disqus、artalk
Twikoo
twikoo.envId：环境 ID 或后端地址
twikoo.lang：语言设置，默认 "zh-CN"
twikoo.visitorCount：是否启用访问量统计，默认 true
Waline
waline.serverURL：后端服务地址
waline.lang：语言设置，默认 "zh-CN"
waline.login：登录模式（enable/force/disable），默认 "enable"
Artalk
artalk.server：后端 API 地址
artalk.locale：语言设置，默认 "zh-CN"
Giscus
giscus.repo：GitHub 仓库（owner/repo）
giscus.repoId：仓库 ID
giscus.category：Discussion 分类名
giscus.categoryId：分类 ID
Disqus
disqus.shortname：Disqus shortname
4.6 音乐播放器（musicConfig.ts）
基础配置
showInNavbar：是否在导航栏显示入口，默认 true
mode：使用方式（meting/local），默认 "meting"
volume：默认音量（0-1），默认 0.7
playMode：播放模式（list/one/random），默认 "list"
showLyrics：是否启用歌词显示，默认 true
Meting API 模式
meting.server：音乐平台（netease/tencent/kugou/xiami/baidu），默认 "netease"
meting.type：类型（song/playlist/album/search/artist），默认 "playlist"
meting.id：歌单 / 专辑 / 单曲 ID 或搜索关键词
本地音乐模式
播放列表项属性：name、artist、url、cover、lrc
4.7 封面图片（coverImageConfig.ts）
enableInPost：是否在文章详情页显示封面图，默认 true
randomCoverImage.enable：是否启用随机封面图，默认 false
randomCoverImage.apis：随机图 API 列表
randomCoverImage.fallback：API 失败时的回退图片
使用方式：在文章 Frontmatter 中设置 image: "api"
4.8 特效设置（effectsConfig.ts）
樱花特效
enable：是否启用樱花特效，默认 false
switchable：是否允许用户切换，默认 true
sakuraNum：樱花数量，默认 21
limitTimes：越界限制次数，-1 为无限循环
size.min/max：尺寸倍数范围
opacity.min/max：不透明度范围
speed.horizontal/vertical/rotation/fadeSpeed：移动速度
五、页面配置
5.1 番组计划
展示 Bangumi 上的收藏记录，支持动画、书籍、音乐、游戏等多种类型。
启用：siteConfig.ts 中 pages.bangumi: true
数据模式：static（构建时获取）、dynamic（浏览器实时请求，推荐）
条目类型：anime、book、music、game、real
5.2 追番页面
展示动漫追番记录，支持从 Bilibili 和 TMDB 两个数据源获取数据。
启用：siteConfig.ts 中 pages.anime: true
Bilibili 配置：anime.bilibili.uid
TMDB 配置（可选）：anime.tmdb.apiKey、anime.tmdb.listId
数据合并：同时配置时自动合并，Bilibili 数据优先，按标题去重
5.3 公告（announcementConfig.ts）
title：公告标题，默认 "公告"
content：公告内容
icon：公告图标
type：公告类型（info/warning/success/error）
closable：是否允许用户关闭公告，默认 true
5.4 页脚（footerConfig.ts + FooterConfig.html）
enable：是否启用 Footer HTML 注入功能，默认 false
自定义内容：直接编辑 FooterConfig.html 文件
5.5 广告
配置在 sidebarConfig.ts 的 advertisement 组件中。
title：广告标题
content：广告文本内容
image：图片配置（src、alt、link、external）
link：链接配置（text、url、external）
closable：是否可关闭
displayCount：显示次数限制，-1 为无限制
expireDate：过期时间（ISO 8601 格式）
5.6 许可证（licenseConfig.ts）
enable：是否在文章顶部显示许可证信息，默认 true
name：许可证名称，默认 "CC BY-NC-SA 4.0"
url：许可证链接
常用许可证：CC BY 4.0、CC BY-SA 4.0、CC BY-NC 4.0、CC BY-NC-SA 4.0、CC BY-ND 4.0、CC BY-NC-ND 4.0
5.7 友链（friendsConfig.ts）
页面配置
title：页面标题
description：页面描述
showCustomContent：是否显示底部自定义内容，默认 true
showComment：是否显示评论区，默认 true
randomizeSort：是否开启随机排序，默认 false
友链项属性
title：友链标题
imgurl：头像图片 URL
desc：友链描述
siteurl：友链地址
tags：标签数组
weight：权重，数字越大排序越靠前
enabled：是否启用
5.8 相册（galleryConfig.ts）
两级结构：首页展示相册封面卡片，详情页瀑布流展示照片。
相册属性
id：相册唯一标识符
name：相册名称
description：相册描述
date：日期（YYYY-MM-DD）
location：拍摄地点
tags：标签，用于首页筛选
cover：手动指定封面图
password：相册密码
passwordHint：密码提示信息
全局配置
columnWidth：瀑布流最小列宽（px），默认 240
封面图规则
按优先级：手动指定 > cover 文件 > 第一张图片
页面路由
/gallery/- 相册首页
/gallery/{id}/- 相册详情页
5.9 打赏（sponsorConfig.ts）
基础配置
title：页面标题
description：页面描述
usage：打赏用途说明
showSponsorsList：是否显示打赏者列表，默认 true
showComment：是否显示评论区，默认 true
showButtonInPost：是否在文章底部显示打赏按钮，默认 true
打赏方式属性
name：打赏方式名称
icon：图标
qrCode：收款码图片路径
link：打赏链接 URL
description：描述文本
enabled：是否启用
5.10 Live2D / Spine 模型（看板娘）（pioConfig.ts）
二选一使用。
Spine 模型配置
enable：是否启用
model.path：模型文件路径
model.scale：缩放比例
position.corner：显示位置（bottom-left/bottom-right/top-left/top-right）
size.width/height：容器尺寸
interactive.enabled：是否启用交互功能
interactive.clickAnimations：点击动画列表
interactive.clickMessages：点击消息列表
responsive.hideOnMobile：是否在移动端隐藏
Live2D 模型配置
基于 l2d-widget 组件，支持 Cubism 2 和 Cubism 6 格式。
enable：是否启用
model.path：模型文件路径，支持外部 URL
model.volume：动作声音音量，默认 0（静音）
position：显示位置（bottom-left/bottom-right）
size：画布尺寸
primaryColor：主题色
transitionDuration：入场 / 退场动画时长
transitionType：动画类型（slide/fade）
menus.items/extraItems：菜单配置
tips.enable：提示气泡开关
tips.welcomeMessage：欢迎语
tips.messages：循环提示内容
responsive.hideOnMobile：是否在移动端隐藏
